# 🚗 Car Rental Web Demo

A clean, interactive **car rental web demo** built using HTML, CSS, and JavaScript.  
It allows users to select pickup and drop-off times and locations while dynamically updating available cars and pricing through event listeners.

---

## 🌐 Live Demo  
👉 [View the Site](https://ntando-beta.github.io/carrental/)

---

## 🧠 About the Project
This project was created to simulate the front-end experience of a car rental company website.  
The goal was to demonstrate DOM manipulation, user input handling, and simple UI logic without any backend server.

---

## ⚙️ Features
- 📅 Select pickup and drop-off dates & times  
- 🚘 Dynamic updates using JavaScript event listeners  
- 📱 Responsive layout for desktop and mobile  
- 💬 Interactive sections and clean design  

---

## 🧰 Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
